# 🔍 Repo Finder

Welcome to **Repo Finder**! This web application allows you to discover GitHub repositories based on your preferred programming language. Whether you're looking to explore new projects or find inspiration, Repo Finder makes the process seamless and enjoyable.

## 🚀 Features

- **Dynamic Language Selection:** Choose from a wide range of programming languages to tailor your repository search.
- **Random Repository Discovery:** Get introduced to random repositories, broadening your exposure to diverse projects.
- **Detailed Repository Information:** View essential details such as repository name, description, stars, forks, and open issues.
- **User-Friendly Interface:** Navigate the application with ease, thanks to its intuitive design.

## 🛠️ How It Works

1. **Select a Programming Language:** Use the dropdown menu to choose your desired language.
2. **View Repository Details:** The app fetches and displays a random repository matching the selected language.
3. **Explore More:** Click the "Refresh" button to discover another repository.

## 🎨 Tech Stack

- **Frontend:** HTML, SCSS, JavaScript
- **API:** GitHub Search API
